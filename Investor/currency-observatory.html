How the basket index works

No currency has an absolute or universally neutral price. This page uses a custom nominal index: each currency is measured against the other 19 currencies, with equal weights and a geometric average. Using USD to calculate the cross rates does not make USD the basket benchmark.

Iᵢ(t) = 100 × exp[meanⱼ≠ᵢ ln((rⱼ(t) / rᵢ(t)) / (rⱼ(base) / rᵢ(base)))]

rᵢ is units of currency i per USD; rUSD = 1. Each peer has weight 1/19. An index of 110 means a 10% appreciation against that currency’s peer basket since the base date. It does not mean the currency is expensive or undervalued. This is a custom basket index, not DXY or an official BIS effective exchange rate.

1D compares the previous complete observation. 1W is seven calendar days; 1M, 6M and 1Y use calendar offsets, clamped to month-end. A non-working comparison date uses the latest complete observation on or before it, at most seven days earlier. Dates missing any basket currency are excluded; values are never silently substituted.

Changing the percentage benchmark leaves the basket-index and spot-rate columns unchanged. USD against USD and CNY against CNY necessarily have 0% changes.

Sources, coverage and API options

Rates: Frankfurter v2, filtered to the European Central Bank. Daily reference rates, not executable or intraday quotes. The page refreshes on opening and on request; a dated embedded snapshot stays available if the API cannot be reached.

Default order follows BIS April 2025 FX turnover by currency within this selected watchlist. Malaysia is included by request. This is not a strict global top 20, a GDP ranking, a capital-flow measure, or a stock-market-size ranking. EUR represents the euro area, including Germany. HKD is shown as a currency jurisdiction.

For official trade-weighted indices, use BIS nominal effective exchange rates (daily observations, published with a lag). For intraday FX, Twelve Data offers registered API access; check all required pairs and plan limits before switching. An account-based replacement should run through a server to keep its key private.

The rate adapter is fetchRates(from) in this HTML file. It accepts Frankfurter rows shaped as {date, base: "USD", quote, rate}, where rate is currency units per USD. An alternative provider must normalize to that format and daily observation convention.
